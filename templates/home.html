Welcome to the Healthcare Management API

This API provides secure healthcare workflows including token-based authentication (JWT), scoped patient records management, doctor directory maintenance, and patient-doctor clinical assignments.

Browsable API Login Django Admin Panel

ⓘ API Usage & JWT Authentication Guide

  1. Register an account: Send a POST request to {% url 'register' %} with name, email, and password (min 8 chars).
  2. Authenticate: Send a POST request to {% url 'login' %} with your credentials to obtain JWT access and refresh tokens.
  3. Access Protected Resources: Include the header Authorization: Bearer <your_access_token> in subsequent requests.
  4. Interactive Testing: For browser-based testing via Django REST Framework's browsable interface, log in via Session Login. For POST/PUT/DELETE requests with JWT, use Postman, Insomnia, or cURL.

1. Authentication

User registration & SimpleJWT token issuance

POST {% url 'register' %}
Register new user account (name, email, password)
POST {% url 'login' %}
Authenticate & receive JWT access and refresh tokens

Note: Auth endpoints require HTTP POST with a JSON payload. Test via Postman or the Browsable API.

2. Patient Management

Scoped records (users can only access owned patients)

GET {% url 'patient-list' %}
List all patient records belonging to the authenticated user
POST {% url 'patient-list' %}
Create a new patient record (name, age 0-120, gender, phone, address)
GET /api/patients/<id>/
Retrieve an owned patient record
PUT / PATCH /api/patients/<id>/
Update or partially update an owned patient record
DELETE /api/patients/<id>/
Delete an owned patient record
Browse Patients (GET)

3. Doctor Management

Medical professional directory and profiles

GET {% url 'doctor-list' %}
List all registered medical doctors
POST {% url 'doctor-list' %}
Register a new doctor (name, specialization, phone, unique email)
GET /api/doctors/<id>/
Retrieve doctor profile details
PUT / PATCH /api/doctors/<id>/
Update doctor contact or specialization details
DELETE /api/doctors/<id>/
Remove doctor from directory
Browse Doctors (GET)

4. Patient-Doctor Mappings

Clinical assignments with unambiguous routing

POST {% url 'mapping-list-create' %}
Assign doctor to an owned patient (patient, doctor)
GET {% url 'mapping-list-create' %}
List all assignments for the authenticated user's patients
GET /api/mappings/patient/<patient_id>/
Explicit endpoint: Retrieve all doctor assignments for a specific patient
GET /api/mappings/<mapping_id>/
Retrieve a specific assignment by its mapping ID
DELETE /api/mappings/<mapping_id>/
Explicit endpoint: Delete a specific assignment by its mapping ID
Browse Mappings (GET)
